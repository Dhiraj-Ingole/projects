# Import What's New D2 into Elementor

File: `elementor-whats-new-d2.json`

This template is built **section by section to match the HTML preview**, using native Elementor containers and widgets:

| Section | Elementor elements |
|---|---|
| Hero | Full-width container + background photo + right-side copy (heading, text, button) + gradient overlay CSS |
| Intro | Cream paper card, two text columns |
| Spotlight | Photo band, copy left, featured card (image, headings, button) right |
| Partners | Heading + text + HTML cover tiles (same photos/logos/links as the live page) |
| Education | Photo header, copy on the right, overlay |
| Education / Doctors / Survivors / Blogs grids | Unlimited Elements magazine grids from the original page (dynamic posts) |
| Newsletter | Quote layout + live ConvertKit form |
| Discussions | Photo pane + copy + button |
| Survivors | Washed photo + panel + grid |
| Blogs | Split title + framed photo + grid |

## Why the earlier imports looked like the old page

Those files started from the **original 14-section What’s New export** (purple waves, Happy Addons headlines, old overlays) and only tweaked colors. The D2 layout never replaced that structure.

This file does what the HTML does: new containers, new overlays, copy on the right, photo partner tiles, split Spotlight and Discussions.

## Import

1. Remove the previous template from the page (old sections will otherwise stay visible).
2. Templates → Saved Templates → Import Templates
3. Upload `elementor-whats-new-d2.json`
4. Insert **What's New — D2 Cinematic** and publish

Images use existing `wp-content/uploads` URLs. Do not re-upload media.
